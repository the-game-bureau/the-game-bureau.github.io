You are updating this dataset of every team in the major North American pro sports leagues. The four CORE leagues are NFL, NBA, NHL, and MLB; additional leagues (e.g. MLS) may be added with the same fields. This JSON file holds your instructions (this field) plus a "teams" array. Bring the "teams" array fully up to date as of today and return the SAME JSON structure (this field unchanged, plus the updated array). Verify against authoritative, current sources before changing anything.

SCOPE: {{keywords}}
EXTRA DIRECTION: {{notes}}

Fields per team:
- TGBID: a permanent unique integer id for the team ("The Game Bureau ID"). The New Orleans Saints are 1. Once assigned, a team's TGBID NEVER changes and is NEVER reused, even if the team is removed.
- League: NFL | NBA | NHL | MLB (or another league code, e.g. MLS, when extending).
- GeoName: the geographic descriptor in the official team name (e.g. "New England", "Golden State"). Use "" for the Athletics, who currently carry no city/region name.
- MascotName: the team nickname (e.g. "Saints", "Warriors").
- TGBGameCity: nearest big/anchor city the franchise is identified with, formatted "City, ST". EDITORIAL judgment, not a lookup. PRESERVE the existing value for any team already listed; only set it for a brand-new team.
- VenueCity: the municipality where the home venue physically sits, formatted "City, ST" (e.g. "Foxborough, MA"). For an existing team, keep it unless the team has actually changed venues.
- EspnId: ESPN's numeric team id (the "id" field in ESPN's team list). MUST be populated for every team, existing and new.
- code, conference, fullName, firstName, fanbase, mascot, sport: site/runtime aliases derived from the team identity. Preserve existing values unless identity actually changes.
- primary, secondary, tertiary: team palette colors as #RRGGBB hex strings. These are the canonical palette field names.
- paletteSource: where the palette came from (e.g. supabase or espn). Preserve existing values unless refreshing palette data.

Rules:
1. ADD any team that now exists but is missing. Pull GeoName, MascotName, and EspnId from ESPN's team list. For VenueCity, do NOT just copy ESPN's metro label — determine the actual municipality the home venue physically sits in (e.g. the stadium is in "Paradise, NV", not "Las Vegas, NV"; "Foxborough, MA", not "Boston, MA") by checking the venue's real location, and note your source for it. Set TGBGameCity by your editorial judgment of the nearest big city. Format both as "City, ST". Assign TGBID = (the highest TGBID currently in the array) + 1.
2. REMOVE any franchise that no longer exists.
3. EDIT GeoName/MascotName/VenueCity when a team rebrands or relocates. A pure rename of the same franchise (e.g. Cleveland Indians to Guardians, Washington Football Team to Commanders) is an EDIT, not a remove+add; keep its existing EspnId since ESPN keeps the same id through a rename.
4. Do NOT overwrite TGBGameCity or VenueCity for teams that have not moved — those are curated by hand.
5. Keep the Athletics' GeoName as "".
6. Populate/refresh EspnId for EVERY team from ESPN's team list (the "id" field). Do not leave it blank.
7. Expected counts for the four core leagues: NFL 32, NBA 30, NHL 32, MLB 30 (124 total). Note it if your result differs. Teams from any added league (e.g. MLS) are extra, beyond this count.
8. Source: ESPN's public team lists at https://site.api.espn.com/apis/site/v2/sports/{sport}/{league}/teams (football/nfl, basketball/nba, hockey/nhl, baseball/mlb; soccer/usa.1 for MLS) provide, per team, League, GeoName (location), MascotName (name), and EspnId (id).
9. TGBID is a permanent key: never renumber existing teams, never reuse a removed team's number, and never change the Saints from 1. A new team always takes the next available number = max(TGBID) + 1.
10. EXTENDING TO A NEW LEAGUE (e.g. MLS): only when SCOPE/EXTRA asks for it. Add that league's teams with the same fields and its own League code, assigning each the next free TGBID; do not touch the core four leagues' rosters in the process.
