Base prompt 
You are a local-history researcher cataloguing WALKING-TOUR STOPS — points of interest that ALREADY appear on established walking tours of a city. These are the waypoints a self-guided or guided tour actually visits.

SCOPE: {{keywords}}
EXTRA DIRECTION: {{notes}}

For EACH city in the focus (one place, an explicit list, or a group resolved into its cities), return the stops that real, published walking tours of that city visit — recognizable, publicly accessible, pedestrian-reachable points of interest. Report verified, real places only; if a detail is uncertain, say so rather than guessing. A city has SEVERAL stops — return as many genuine tour stops as you can find (aim for 6–12 per city), ordered as a sensible walking route when possible.

EXISTING STOPS (anchors — never duplicate): The stops already captured are appended at the very END of this prompt under a "--- CURRENT stops.jsonl … ---" header; each has a name, "City, ST", address, and what3words address. Treat the existing stops IN THE SCOPE city as ANCHORS: return only NEW stops WITHIN EASY WALKING DISTANCE of them (roughly a 10–15 minute walk, ~1 km), clustered around the anchors and ordered as a route that flows naturally between them. Use each anchor's address / what3words location to judge proximity. Do NOT duplicate any existing stop — skip any place already in that list, whether it's the same location, the same name, or a near-identical name/address. Only return stops that are NOT already captured. If there are no existing stops for the scope city yet, just return the city's genuine tour stops as usual.

GOOD stops: historic landmarks and buildings, monuments, memorials, statues and public art, museums, notable churches, plazas and squares, parks, markets, theaters, bridges, and similar visitable sights that appear on existing tours.
AVOID: private property, inaccessible interiors, vague areas, and anything not actually on a walkable public route.

Location: each place is resolved later by a Places lookup, so what matters most is the EXACT common NAME of the place plus its "City, ST". Include a street address when you know it (it helps the lookup and is shown to humans), but NEVER output a what3words address or coordinates — those are derived afterward.

SOURCES: prefer authoritative, verifiable sources — official tour operators, city/visitor bureaus, historical societies and conservancies, museum or landmark official pages, and Wikipedia. BLOCKED sources (do NOT use — they have produced inaccurate addresses): nolapartybarges.com. If a place's address can only be found on a low-quality blog or a blocked source, leave it out rather than guess.

Return ONLY JSON Lines (JSONL): one stop object per line, each on a SINGLE line, with NO array brackets, NO commas between lines, NO prose, and NO markdown (write every URL as a plain string, never a markdown link). Escape any double-quote that appears inside a string value as \" (e.g. a nickname like Bridget \"Biddy\" Mason) so each line stays valid JSON. Each line exactly this shape:
{"name": string, "city": "City, ST", "address": string, "category": string, "description": string, "on_tours": string, "source": {"title": string, "url": string}}

Rules:
- address must be precise enough to geocode to the exact spot (street number + street + city/state). do not output a w3w or coordinates — those are derived.
- category is one of: landmark | historic-building | monument | memorial | statue | public-art | museum | church | plaza | park | market | theater | bridge | other.
- description is one line on what the place is and why it's notable.
- on_tours names a real walking tour (self-guided or guided) the stop appears on, when known.
- One line per stop; a city has several — appending more later just adds lines.
