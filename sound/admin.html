1 How It Works

The public page /sound/ renders the cassette grid at runtime.

  • City identity Names, labels, order, geo badges, tape colors, and Spotify playlist ids come from public.cities, keyed by slug.
  • Track lists Songs live in sound/soundtracks.json, keyed by city_slug.
  • Cassette spine copy Optional spine_tag and spine_tag_position values live beside each city's songs.

There is no build step. Edit the JSON, deploy, then hard-refresh the public page if cached data lingers.

3 Add Or Edit A Track

  1. Pick the song. Use local artists, sports and stadium cues, and songs that name the place. Aim for exactly 10 songs per city, max 2 per artist.
  2. Get its Spotify track ID. Copy the Spotify song link. The ID is the 22-character value after /track/, before any ?.
  3. Confirm the track and explicit flag. Use the real track, not karaoke or re-recorded versions. If Spotify marks it explicit, set "explicit": true.
  4. Edit sound/soundtracks.json. Find the matching city_slug and add, edit, reorder, or remove song objects in that city's songs array.
  5. Deploy. The public page fetches the JSON on load, so the change appears on the next uncached visit.
{
  "city_slug": "new-orleans",
  "spine_tag": "Soundtrack",
  "songs": [
    {
      "title": "Iko Iko",
      "artist": "The Dixie Cups",
      "spotifyId": "2xZPpUIcajScKX99PH0fD9",
      "blurb": "Mardi Gras Indian chant from a homegrown girl group",
      "explicit": false
    }
  ]
}

4 Data Fields

Field Where What It Controls
city_slug soundtracks.json Matches public.cities.slug. Without a matching city row, the tape will not appear in the main city catalog.
spine_tag soundtracks.json Extra cassette-spine copy such as Soundtrack, Jams, or Mix Tape.
spine_tag_position soundtracks.json Set to before for phrases like Sounds of. Omit it for normal after-city labels.
title songs[] Track name shown on the cassette label.
artist songs[] Performing artist.
spotifyId songs[] Spotify track ID. If empty, the cassette falls back to a Spotify search for artist plus title.
blurb songs[] Short why-it-fits line, ideally 6 to 9 words.
explicit songs[] Use true to show the explicit tile. Omit or set false for clean tracks.

5 Add A City

  1. Add or update the city row in public.cities. Required for /sound/: slug, city, city_name, sort_order, and structured geo fields where available.
  2. Optional sound city fields: sound_playlist_id, sound_accent, and sound_secondary.
  3. Add a matching soundtracks.json entry using the same city_slug.
  4. Leave ignored as false. A city marked ignored = true is venue-only — somewhere a team plays, not somewhere we make a tape — and /sound/ hides it, playlist or not.

The migration that introduced the city-backed sound data lives at supabase/migrations/2026071501_cities_soundtracks.sql. The ignored flag arrived in supabase/migrations/2026072205_cities_ignored.sql.

6 Quality Bar

  • Prefer hometown artists, songs about the city, and recognizable game-day cues.
  • Keep the mix varied across eras and genres when the city supports it.
  • Use real Spotify tracks with stable IDs whenever possible.
  • Keep blurbs short enough to fit the cassette label cleanly.

Editing or removing a track is the same path: update the object in that city's songs array and deploy.
