# Cassette Player Assets

These image slices are the Codrops demo exports from Mauricio Estrella's cassette PSD:

- Source demo: https://tympanus.net/Development/CassettePlayer/
- Codrops writeup: https://tympanus.net/codrops/2012/07/12/old-school-cassette-player-with-html5-audio/
- Original PSD credit: Mauricio Estrella / Manicho, "Cassette - PSD File"

`cs_front.png` has been locally edited to remove the original "Codrops Sounds" sample text from the title strip and replace the lower-left "ME / DEVART123" mark with "The Game Bureau". The replacement mark is text-only, with no backing fill.
