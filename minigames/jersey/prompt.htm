THE JERSEY GAME Record Prompt

Use this page when generating new Supabase seed records for jersey_game.

Copyable Prompt

Quick Reference

  • player1num + player2num = player3num or player1num - player2num = player3num.
  • Use first-initial display names like S. Mills, not MILLS.
  • City-mate pro teams are allowed, such as Knicks and Jets for New York.
  • Future batches can cover up to ten teams and can use NFL, NBA, MLB, and NHL teams even if TGB has not used them yet.
  • The game validates all three jersey numbers against the database row.
  • Each number must match the player's number on the cited team (numbers change between teams); for multi-number cases like Kobe, Jordan, or Mark Ingram, use the original number.
  • Before applying, spot-check 5 random rows to confirm the numbers fit the cited teams.
  • The hint button fills jersey 3, so jersey 3 should be a satisfying known-player answer.
