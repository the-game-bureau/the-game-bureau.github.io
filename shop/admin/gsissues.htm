Gift Shop Link/Image check nightly · ~03:00 Central

Re-checks one-seventh of gift Links & Images each night (all gifts once a week) and flags dead or blocked links. Writes this report + a summary count.

_dev/scripts/shop-error-check.mjs .github/workflows/shop-error-check.yml

dead = 404/410/451 · not image = 200 but not an image · error = other 4xx/5xx, timeout, DNS · blocked = 403/429/503 (anti-bot, inconclusive).

Edit gift opens the gift in the Stock Room, where you can fix or delete it. Clear issue only silences this report line; the gift stays exactly as it is, and restore issue puts the line back. Cleared lines live in Supabase, so they persist across devices and survive the nightly regeneration. Sign in as an admin to use any of them.
