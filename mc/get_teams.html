Base prompt 
You are maintaining the Game Bureau Supabase "teams" table — every team in the major North American pro sports leagues. CORE leagues: NFL, NBA, NHL, MLB. Others (e.g. MLS) may be added using the SAME columns. Return team rows using EXACTLY these column names (see OUTPUT below for the exact format). Verify against authoritative, current sources before changing anything.

SCOPE: {{keywords}}
EXTRA DIRECTION: {{notes}}

Columns per team (the table's real column names):
- league: NFL | NBA | NHL | MLB (or another league code, e.g. MLS).
- conference: conference/group name, or "" if none. Part of the primary key.
- division: the sub-group within the conference — just the division name, NOT prefixed with the conference (e.g. "North"/"South"/"East"/"West" for NFL & MLB; "Atlantic"/"Central"/"Southeast"/"Northwest"/"Pacific"/"Southwest" for NBA; "Atlantic"/"Metropolitan"/"Central"/"Pacific" for NHL), or "" if none. Editable metadata, not part of the key.
- code: short team code, uppercase (e.g. "NO", "CHC", "ARI"). Part of the primary key; with league it forms the stable team_key = LEAGUE:CODE that games reference. NEVER change an existing team's code; keep it unique within the league.
- full_name: full team name (e.g. "New Orleans Saints").
- first_name: geographic descriptor in the official name (e.g. "New England", "Golden State"). "" for the Athletics.
- fanbase: the nearest BIG city to the venue, as "City, ST" with a 2-letter state/province. MUST be a real city — never a region or state (use "Phoenix, AZ" not "Arizona, AZ"; "Charlotte, NC" not "Carolina, NC"). It may equal venue_city/game_city. When the team's name contains a real city, prefer it (49ers → "San Francisco, CA", Clippers → "Los Angeles, CA").
- mascot: the nickname (e.g. "Saints").
- sport: football | basketball | hockey | baseball (or the league's sport).
- shell / stripe / mask: primary / secondary / tertiary palette colors as #RRGGBB hex.
- text_color: the team's text/fourth color as #RRGGBB (default "#FFFFFF").
- game_city: nearest big/anchor city, "City, ST". Editorial judgment. PRESERVE existing values; only set for a brand-new team.
- venue_city: municipality the home venue physically sits in, "City, ST" (e.g. "Foxborough, MA", not "Boston, MA"). PRESERVE unless the team actually moved.
- timezone: IANA timezone of the venue (e.g. "America/Chicago").
- tgbid: permanent unique integer id. Once assigned it NEVER changes and is NEVER reused. New team = (max existing tgbid) + 1.
- espn_id: ESPN's numeric team id (the "id" field in ESPN's team list).
- league_sort / team_sort: integer ordering (NFL pinned first). Preserve existing values.

Rules:
1. ADD a missing team with all columns. Assign code (short, uppercase, unique in the league), tgbid = max existing + 1, espn_id from ESPN, editorial game_city, and the venue's real municipality for venue_city.
2. NEVER change an existing team's league or code — team_key is foreign-keyed by games. A rebrand/rename (e.g. Indians→Guardians) EDITS full_name/first_name/mascot but keeps league, code, tgbid, and espn_id.
3. Do NOT overwrite game_city/venue_city/timezone for teams that haven't moved — those are curated by hand.
4. Keep the Athletics' first_name as "".
5. Do NOT output team_key or updated_at: team_key is generated from league+code, updated_at is automatic.
6. Expected core counts: NFL 32, NBA 30, NHL 32, MLB 30 (124 total). Note it if your result differs. Added leagues (e.g. MLS) are extra.
7. Source: ESPN public team lists at https://site.api.espn.com/apis/site/v2/sports/{sport}/{league}/teams (football/nfl, basketball/nba, hockey/nhl, baseball/mlb; soccer/usa.1 for MLS) provide league, first_name (location), mascot (name), and espn_id (id).

OUTPUT — your reply OVERWRITES the Supabase teams table. The page upserts every row you return by team_key (LEAGUE:CODE): existing teams are updated in place, new teams are inserted, and nothing is deleted. Because nothing is deleted, your reply MUST be the COMPLETE table.

Hard rules (these make the overwrite safe — follow ALL of them):
1. Return EVERY existing team. Every team in the Current Data provided alongside this prompt must appear in your output, even ones you did not change. Never drop a team.
2. Identity is permanent: for an existing team you may NOT edit its league, code, or tgbid. Copy each existing team's league, code, and tgbid through UNCHANGED. (team_key = LEAGUE:CODE is derived and is foreign-keyed by games — do not output team_key.)
3. You MAY edit any OTHER field of any team: full_name, first_name, fanbase, mascot, sport, conference, division, shell, stripe, mask, text_color, game_city, venue_city, timezone, league_sort, team_sort.
4. You MAY add brand-new teams. A new team gets a code unique within its league and tgbid = (highest existing tgbid) + 1. Only brand-new teams get a new tgbid.

Format: one team per line as an object literal with the exact column keys above — e.g. {"league":"NFL","conference":"","code":"NO","full_name":"New Orleans Saints", ...}. No surrounding brackets, no prose, no markdown, no commentary.
