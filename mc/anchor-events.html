ANCHOR EVENTS

The shared catalog of real-world events a game can be anchored to — a concert, convention, festival, expo, sports matchup, anything. Import in bulk, add one at a time, or edit below. A sports event can also link the two teams (by tgbid) so the builder auto-fills a game's away/home teams; other kinds just need a title. During game building you pick an event from here.

Bulk import (paste JSON)

Paste a JSON array or JSONL (one object per line). Recognized keys: id/game_id, kind/type, title/name, date/event_date, end_date, start_time/time, venue, city, status, url/link, description, source — plus sports: league/sport, away_tgbid/away_team_tgbid, home_tgbid/home_team_tgbid, away/home (labels), away_score/home_score. Rows re-import by id (upsert). Kind defaults to sports when teams are present.

Add an event

Sports only — pick the two teams (leave blank for concerts, conventions, etc.). Filling these links to the teams catalog and lets the builder auto-fill a game's away/home teams.
