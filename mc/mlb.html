MLB Game Generator

Generate MLB "Fans Takeover" games from the live schedule, preview them, pick the ones you want, and push only those to Supabase.

1 · Generate the file

Run the Node generator to pull the MLB schedule from ESPN and write mc/data/mlb.jsonl. It never touches the database — that happens here, after you choose. Scope is required (a full season is ~2,400 games).

node _dev/scripts/mlb_matchup_maker.js --team NYM node _dev/scripts/mlb_matchup_maker.js --start 2026-07-01 --end 2026-07-07 node _dev/scripts/mlb_matchup_maker.js --start 2026-03-25 --end 2026-11-15 # full season
